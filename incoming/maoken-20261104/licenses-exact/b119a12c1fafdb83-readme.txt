■ (｡･･｡)b　～ せつめい　----------------------------------------------------------------
	
	
	力強いストロークとゆるやかな独自の味わいが特徴のフリーフォント
	『お手製Rwiフォント』（Otesei-Rwi-Font）です。
	
	自由なライセンスのもと提供されているフリーフォント
	　『M+ FONTS』（M PLUS 1p）（http://mplus-fonts.osdn.jp/about2.html）
	の字形を元に、独自のストロークブラシを使い一文字ずつ手書きで作成、
	およびソフト上での調整を施し制作を行いました。
  	
 	
 	
	ライセンス(利用規約) は「M+ FONT LICENCE」と同様の
	とても自由なライセンスとなります。
	ゲーム等への組み込み使用、Webフォント化、改変、再配布等、
	煮るなり焼くなりご自由にどうぞ。
	
	もしお気に召しましたら、ご支援（Donate）をいただけますと非常に嬉しいです。
	また、当フォントの紹介やご使用報告等をいただけますと飛び上がって喜びます👍

● 更新履歴　-------------------------------------------------------------------------
	
	
　【ver1.0】 2020.11.24　完成
　	・全3805文字
	・手書きでひらがな、カタカナ、記号類、第一水準漢字（全2965字）等を作成
	
	
　【ver2.0】 2021.01.24　完成
　	・全3807文字
	・全ての漢字の字形をソフト上で調整
	・漢字の字形を少し重心上げめに、クール寄りに
	・小さいサイズでの表示でも、垂直・水平な線がつぶれずキレイに表示されやすく
	
	
　【ver3.0】 2022.08.27　完成 および 過去バージョンとともに初公開
　	・全4668文字
　	・第二水準漢字の一部（861字）を新規作成&一部調整
　	・漢字以外の文字もver2.0相当の調整を行い、綺麗に表示されるように
　	・ひらがな、カタカナの字間・サイズを調節
	・縦書き用文字を仮作成
　【Update】 2022.10.09　多数の「実験フォント」を追加
	・太字化、細字化、袋文字、白黒反転、立体、上下斜体変形、左右斜体変形、高さ半分、横幅半分、角丸、角立ち
	・詳細は付属の readme にて
