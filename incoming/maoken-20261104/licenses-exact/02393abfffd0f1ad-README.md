# 檎风黑体

檎风黑体，基于 [Pretendard Std](https://github.com/orioncactus/pretendard/tree/main/packages/pretendard-std)、[思源黑体](https://github.com/adobe-fonts/source-han-sans)和[秋空黑体 MN](https://github.com/ChiuMing-Neko/ChiuKongGothic)，商用免费的 CJK 字体。

## 制作动机

受到[更纱圆纪黑体](https://fonts.zeoseven.com/items/617/)的启发（该字体旨在参考 [San Francisco](https://developer.apple.com/fonts/)，还原[更纱黑体](https://github.com/be5invis/Sarasa-Gothic)的`G`为 Inter 原版样式），将 Inter 替换为 Pretendard Std。[Pretendard](https://cactus.tistory.com/306) 由 Kil Hyung-jin（길형진）设计制作，该字体将 Inter 斜切的文字改为平切设计，使之更像 San Francisco 字体。

同时[鉴于市面上有需要区分`I`和`l`的呼声](https://github.com/be5invis/Sarasa-Gothic/issues/425)，提供`檎风黑体 Alt`。

## 字名解读

- 风格
  - `檎风黑体`: 使用 Pretendard Std 原版样式
  - `檎风黑体 Alt`: 区分`I`和`l`

- 字形
  - `GB`: 中国内地字形
  - `MN`: [现代笔形印刷体字形](https://github.com/ChiuMing-Neko/ChiuKongGothic#%E7%8F%BE%E4%BB%A3%E7%AD%86%E5%BD%A2%E5%8D%B0%E5%88%B7%E9%AB%94%E5%AD%97%E5%BD%A2%E7%89%88%E6%9C%ACmn)
  - `HC`: 中国香港字形
  - `TC`: 中国台湾字形
  - `JP`: 日本字形
  - `KR`: 韩国字形

## 鸣谢

本字体基于以下字体：

- [更纱黑体](https://github.com/be5invis/Sarasa-Gothic)（构建字体）
- [思源黑体](https://github.com/adobe-fonts/source-han-sans)（CJK 部分）
- [秋空黑体 MN](https://github.com/ChiuMing-Neko/ChiuKongGothic)（`MN` 版本 CJK 部分）
- [Pretendard Std](https://github.com/orioncactus/pretendard/tree/main/packages/pretendard-std)（西文）
