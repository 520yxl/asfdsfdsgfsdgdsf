INTRODUCTION
The Choumei font is a non-serious Kanji font with nearly 7,700 glyphs that I
created out of interest. I am releasing it into the wild in case anyone
finds it useful. I dervied the kanji and some of the other characters
from the Kanji Stroke Order font that I also maintain. I knocked together
the remaining characters in Fontforge. The characters have unusually thin
strokes.

I am no longer maintaining this font, so if you find a problem with it then
you will have to fix it yourself with a tool such as Fontforge.

I named this font after Kamo no Choumei (1155-1216), the Japanese author who
wrote "Life in a Ten-Foot-Square Hut".

INSTALLATION AND USE
Install and use this font as you would any other TrueType font. The other files
in the archive are this readme and the BSD-style copyright notice.

Choumei provides small capitals; access them using the smcp tag. For example,
in XeTeX use

\font\smallcaps="Choumei:+smcp" at 10pt
